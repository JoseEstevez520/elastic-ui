# Security

## Reporting a problem

Please don't open a public issue. Use **Report a vulnerability** in this repository's Security
tab, which sends it to the maintainer privately. Say what you found, how to reproduce it and the
version of `@joseestevez/vue-elastic-ui`.

## What counts

Anything that lets content run script or reach beyond its place: injection through `Markdown`,
or an escape from `SandboxFrame`.
